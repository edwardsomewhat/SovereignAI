```
Generate options, humanize results. Tone: bold, anti-subscription, pro-ownership.
```

```
Generate 3 distinct taglines for [product] and 2 ad copy variants.
[Product description]. Core message: "[core message]."
Tone: [tone]. Taglines: 4-7 words each, different angles.
Ad copy: headline + 2-sentence body + CTA each.
Avoid AI cliches. Output with task_id: '[id]'.
```

- 3 taglines only: 41s
- Loads humanizer skill automatically (2 skill_view calls)

## Video Studio

### Context
```
You are Video Studio from the creative department. Follow video-studio SKILL.md.
Conchai ComfyUI: http://100.69.153.16:8188.
Use native ComfyUI nodes (UNETLoader, CLIPLoader, VAELoader, EmptyHunyuanLatentVideo,
ModelSamplingSD3, KSampler, VAEDecode, VHS_VideoCombine) — NOT WanVideoWrapper.
Wan models in ComfyUI/models/unet/, CLIP in models/clip/, VAE in models/vae/.
VHS_VideoCombine with NVENC. Strip _comment/_meta from JSON.
Poll /history every 10s. Timeout: 600s.
Before building: verify models are real files (not LFS pointers) with
`xxd FILE | head -1` — binary hex = real, ASCII text = pointer.
```

### Goal template
```
Generate a short text-to-video clip on Conchai's ComfyUI using Wan 2.1 T2V 14B fp8.

Prompt: "[video prompt — describe motion, lighting, camera]"
Resolution: 832x480
Length: 33 frames (short for testing)
Steps: 15 (fast)
CFG: 6.0
Output: MP4

Use the native ComfyUI workflow:
- UNETLoader: wan2.1_t2v_14B_fp8_e4m3fn.safetensors, weight_dtype=fp8_e4m3fn
- CLIPLoader: umt5_xxl_fp8_e4m3fn_scaled.safetensors, type=wan
- VAELoader: wan_2.1_vae.safetensors
- EmptyHunyuanLatentVideo: 832x480, length=33
- ModelSamplingSD3: shift=8.0
- KSampler: uni_pc, simple, 15 steps, cfg=6
- VHS_VideoCombine for MP4 output
```

### Proven performance
- Wan T2V 33 frames @ 15 steps: ~300s render
- NVENC hardware encoder on 3090 (verified: `Lavc h264_nvenc`)
- **Timeout risk**: 600s delegate_task timeout is tight — render may complete but monitoring loop times out
- Always verify: `ssh conchai "ls -lt /mnt/hermes_data/comfy/output/ | head -5"`
- Workflow JSON embedded in MP4 metadata

## Review Agent

### ⚠️ Model constraint
Review Agent MUST run on a vision model. When spawned via delegate_task on a
text-only parent (DeepSeek, Claude, GPT-4), it will timeout. Use direct Ollama API as fallback:

```bash
scp /path/to/image.png fated@100.84.92.74:/tmp/review.png
ssh fated@100.84.92.74 "IMG=\$(base64 -w0 /tmp/review.png); curl -s http://localhost:11434/api/chat -d '{\"model\":\"qwen3-vl:8b\",\"stream\":false,\"messages\":[{\"role\":\"user\",\"content\":\"Review this image...\",\"images\":[\"'\"\$IMG\"'\"]}]}' | python3 -c 'import sys,json; print(json.load(sys.stdin)[\"message\"][\"content\"])'"
```

### Goal template
```
Review the [campaign] image at [filepath].
It's a [W]x[H] PNG generated by [model].
Prompt was: "[original generation prompt]"
Check for: AI artifacts, composition quality, brand appropriateness,
any visible text/spelling issues.
Output structured review with scores and SHIP/REJECT verdict.
```
