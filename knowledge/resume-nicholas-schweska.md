## TECHNOLOGY ARCHITECT — **SovereignAI** (2023–Present)

I built a **22-node distributed compute network** from consumer and enterprise hardware, connected via a private Tailscale mesh, running entirely on infrastructure I own and maintain. This is the operational backbone of the Combustion Syndicate and my AI research platform.

### Infrastructure Highlights
- **HP Z8 G4** dual-Xeon server running Proxmox hypervisor
- **RTX 3090 GPU node** (24GB VRAM) for heavy LLM inference and image generation
- **Quadro P5000 node** (16GB VRAM) for secondary compute
- **Jetson Orin Nano Super** with Google Coral TPU for edge AI
- Multi-node **Docker container orchestration** across heterogeneous hardware
- Production services include: LLM inference serving, image generation pipeline (ComfyUI), text-to-speech, workflow automation (n8n), and agent memory systems

### Active Projects
- **Autonomous AI Agent Infrastructure** — reproducible, containerized agent deployment protocol
- **Macho Man Translator** — fine-tuned LLM (Qwen 2.5 1.5B → GGUF) targeting $0.99 mobile release with zero in-app purchases
- **Pi Agent** — self-extending AI agent for creative workflow construction

### Operational Principle
**Anti-SaaS. Anti-rent-seeking.** Every service I run is self-hosted. No cloud dependency. No subscription traps. The user retains sovereignty over their stack.
